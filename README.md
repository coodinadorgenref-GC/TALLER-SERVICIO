# TALLER-SERVICIO
PWA mobile-first para órdenes de servicio de taller (Carabela / Suzuki / Bajaj / Vento).
Estática (GitHub Pages) + Google Apps Script (`gas/taller_api.gs`) + Drive para fotos y firmas.
1. Pega `gas/taller_api.gs` en tu proyecto de Apps Script, cambia `TALLER_CLAVE`, ejecuta `setup()` y publica como Web App.
2. En la app: ⚙ Configuración → pega la URL de la Web App y la clave. Conecta el catálogo con tu correo y PIN.
